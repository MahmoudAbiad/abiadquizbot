الترحيل يضيف جدول `ai_providers` ويحتفظ بصفوف النماذج الحالية وترتيبها. يزرع Gemini وVertex وGroq وOpenAI مرة واحدة، ويحوّل احتياط Groq Vision السابق لفحص المحتوى إلى صف ظاهر قابل للتعديل في سلسلة الفحص. لن يعيد الكود إنشاء أي مزوّد أو نموذج بعد حذفه.

## الاستخدام من البوت

1. افتح لوحة الأدمن ← التحكم بالذكاء الاصطناعي ← **إدارة المزوّدين**.
2. اضغط **إضافة مزوّد** واختر OpenRouter أو Cloudflare Workers AI للإعداد الجاهز، أو **مزوّد آخر / إعداد مخصص** لإدخال المعرّف واسم العرض وواجهة الاتصال.
3. للواجهة المتوافقة مع OpenAI أدخل عنوان API الأساسي مثل `https://api.groq.com/openai/v1`، ثم اسم متغير البيئة مثل `MY_PROVIDER_API_KEYS`. لا ترسل المفتاح نفسه إلى البوت.
4. احفظ بعد مراجعة الإعدادات. أضف النماذج من سلسلة التوليد أو فحص المحتوى أو المسار النصي السريع، وحدد المزوّد المسجّل.
5. من زر **تعديل** بجانب النموذج يمكنك تعديل الاسم والقدرات، مثل `model-name | text,image`.

المزوّد يقبل مفتاحًا واحدًا أو مفاتيح مفصولة بفواصل في متغير البيئة. يوزع المحرك المحاولات بينها، ثم ينتقل إلى النموذج التالي عند الفشل. تغيير النماذج والمزوّدين من اللوحة لا يحتاج نشرًا. إضافة متغير بيئة جديد على منصة الاستضافة قد تحتاج إعادة تشغيل الخدمة بحسب المنصة.

يمكن تعديل اسم العرض وواجهة الاتصال والعنوان واسم متغير البيئة، أو تعطيل المزوّد بنقرة. معرّفه ثابت لحماية ارتباطات النماذج والسجلات؛ لإنشاء معرّف آخر أضف مزوّدًا جديدًا. حذف المزوّد يحتاج تأكيدًا ويحذف نماذجه من السلاسل، مع الاحتفاظ بالكويزات وسجلات الاستخدام والأسعار التاريخية. إذا لم يبقَ نموذج مناسب يتوقف الطلب، دون تشغيل نموذج محذوف خفيةً.

الكاش محلي لمدة 30 ثانية؛ التغييرات تنعكس فورًا على عامل البوت الذي أجرى التعديل، وخلال 30 ثانية على بقية العمال. أثناء انقطاع قاعدة البيانات تُستخدم آخر إعدادات مقروءة إن كانت موجودة، دون قوائم افتراضية ثابتة.

## OpenRouter وCloudflare Workers AI

أضف الأسرار إلى متغيرات بيئة خدمة البوت، ثم أعد تشغيلها إن كانت المنصة تتطلب ذلك:

- **OpenRouter:** متغير `OPENROUTER_API_KEY`. من إضافة مزوّد اختر OpenRouter وراجع الإعداد ثم احفظه. العنوان الجاهز `https://openrouter.ai/api/v1`.
- **Cloudflare Workers AI:** متغير `CLOUDFLARE_API_TOKEN` الخاص بـWorkers AI. من إضافة مزوّد اختر Cloudflare وأدخل **Account ID** المكوّن من 32 خانة من لوحة Cloudflare، ثم احفظ. يُبنى عنوان API الخاص بحسابك تلقائيًا. لا ترسل API Token إلى البوت.

بعد الحفظ أضف اسم النموذج من سلسلة التوليد أو الفحص أو المسار النصي السريع، واختر المزوّد الجديد. انسخ اسم النموذج من كتالوج الشركة؛ مثل `@cf/meta/llama-3.1-8b-instruct` في Workers AI. لا تُضاف نماذج أو تتغير أولوية السلاسل تلقائيًا. إذا كان المزوّد موجودًا بالفعل، يفتح زر الإعداد صفحته الحالية للتعديل.

دعم Workers AI الحالي **نصي فقط** عبر واجهته المتوافقة مع Chat Completions؛ يتجاوز المحرك نماذجه عند وجود صور أو PDF أو صوت. اختر نموذجًا يدعم JSON mode لتوليد الكويز. يدعم OpenRouter النص والصور بحسب النموذج المحدد؛ يُرسل `require_parameters: true` للطلبات المنظمة حتى يختار OpenRouter مسارًا يدعم JSON mode. تبقى قدرات النموذج الفعلية وحدوده شرطًا لنجاح الطلب.

قبول بادئات `@cf/` و`@hf/` يحتاج الترحيل الإضافي `db/migrations/20261017223736_workers_ai_model_names.sql` بعد ترحيل السجل الأول. طُبّق على مشروع الاختبار نفسه بتاريخ 18 أكتوبر 2026، واجتاز اختبار الإضافة والتعديل بصلاحيات خدمة البوت داخل معاملة أُلغيت. لا يغيّر الترحيل النماذج المحفوظة أو ترتيبها أو صلاحيات الدوال.

مراجع الواجهات: [Cloudflare](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/)، [JSON mode](https://developers.cloudflare.com/workers-ai/features/json-mode/)، [OpenRouter routing](https://openrouter.ai/docs/guides/routing/provider-selection#requiring-providers-to-support-all-parameters).

## واجهات الاتصال والقدرات

| الواجهة | المدخلات المدعومة هنا | المصادقة |
|---|---|---|
| `gemini` | نص، صور، PDF، صوت | اسم متغير البيئة الذي يحمل مفاتيح AI Studio |
| `vertex` | نص، صور، PDF، صوت، بحسب حدود الطلب المباشر لدى Google | متغيرات `GOOGLE_VERTEX_PROJECT` و`GOOGLE_VERTEX_LOCATION` و`GOOGLE_VERTEX_SA_KEY_JSON` الحالية |
| `openai_compatible` | نص وصور عبر Chat Completions، مع JSON mode للمخرجات المنظمة | عنوان HTTPS واسم متغير البيئة للمفاتيح |

التوافق مع OpenAI هنا يعني `/chat/completions` بصيغة النص/الصور و`response_format: json_object`، وليس جميع واجهات كل شركة. اختر نموذجًا يدعم هذه الصيغة. نموذج لا يدعم الصور يجب أن تكون قدراته `text` فقط. PDF والصوت في توليد الكويز أو التفريغ يحتاجان حاليًا نموذج Gemini/Vertex مناسبًا. فحص محتوى PDF يستطيع استخدام نموذج صور أيضًا، بتحويل الصفحات إلى دفعات من ثلاث صور فقط في الذاكرة. ضبط قدرات النموذج لا يضيف له قدرة غير موجودة لدى الشركة.

لا تعني عبارة "متغيرات البيئة جاهزة" أن صلاحية المفتاح أو توفر النموذج قد اختُبرا بطلب مدفوع؛ إنها تتحقق من وجود المتغيرات فقط.

## حدود المسؤوليات في الكود

- `helpers/ai_providers_helper.py`: قراءة إعدادات المزوّدين والتحقق منها وحفظها وحذفها.
- `helpers/ai_models_helper.py`: إدارة سلاسل النماذج وأسمائها وقدراتها وترتيبها.
- `services/ai/contracts.py`: طلب ونتيجة وملف مرفق مستقلون عن مكتبات الشركات.
- `services/ai/adapters.py`: تفاصيل الاتصال بكل واجهة، قراءة الاستجابات، التوكنز وتنظيف العملاء والملفات.
- `services/ai/runtime.py`: اختيار النماذج المناسبة وتدوير المفاتيح والتبريد والانتقال للبديل وتسجيل الهوية الحقيقية للمزوّد.
- `helpers/gemini_helper/`: تبقى واجهات إنشاء الكويز القديمة متاحة للمستدعين، مع التخطيط للأجزاء والبرومبت ودمج الأسئلة.

لإضافة شركة تدعم الواجهة المتوافقة يكفي إعدادها من اللوحة. لواجهة مختلفة، مثل واجهة تستخدم بنية طلب أو مصادقة مختلفة، أضف adapter جديدًا، وسجّله في `ADAPTERS` وقائمة الواجهات المسموحة وواجهة الأدمن وقيد قاعدة البيانات؛ لا يحتاج منطق الكويز للتعديل.

توكنز التفكير في واجهة Chat Completions تدخل أصلًا ضمن `completion_tokens`، لذلك تُسجَّل كإخراج دون جمعها مرتين في حساب التكلفة. الأسعار الجديدة غير تلقائية؛ أدخلها في `ai_model_pricing` إذا أردت حساب تكلفة المزوّد والنموذج الجديدين.
