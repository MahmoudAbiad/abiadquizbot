# إعدادات التصدير الإضافية (ورقة الاختبار)

زر **⚙️ إعدادات إضافية** في شاشة اختيار صيغة التصدير (للكويز الحالي ولكويز المفضلة). كل الحقول اختيارية،
وبدون أي تغيير يُصدَّر الملف **تماماً** كما كان (تم التحقق: مخرجات PDF/Word مطابقة للنسخة السابقة).

| الإعداد | القيم | ملاحظات |
|---|---|---|
| عدد الأسئلة بالصفحة | 1 … حد أعلى لكل كويز (سقف مطلق **16**)، أو «تلقائي» | سقف لا حصة: الصفحة التي لا تتسع تحمل أقل |
| عنوان الاختبار | نص ≤ 100 | يستبدل العنوان في الملف واسمه |
| المادة / الصف / التاريخ / المدة | نص ≤ 40 / 30 / 30 / 30 | سطر واحد تحت «عدد الأسئلة»؛ المدة تدخل أيضاً ورقة Excel |
| العلامة الكلية | رقم موجب ≤ 4 خانات | |
| اسم الأستاذ + مكانه | ≤ 60 حرفاً؛ الصفحة الأولى / الأخيرة / ترويسة كل صفحة / تذييل كل صفحة | الافتراضي: الصفحة الأولى |
| بيانات الطالب | ظاهرة/مخفية | هو سطر (الاسم/الشعبة/التاريخ) الموجود أصلاً؛ يُحذف «التاريخ» منه إن حُدّد تاريخ الاختبار |
| الإجابات (نسخة الأستاذ) | مع الشرح / مفتاح فقط | المفتاح: سطر نصي لكل سؤال (صور فقط للمحتوى الرياضي) |
| ترقيم الصفحات | افتراضي / ظاهر / مخفي | الافتراضي: PDF نعم، Word لا (كما كان) |
| تقسيم الصفحة | عمود واحد (الافتراضي) / عمودان | PDF وWord فقط. العربي: العمود الأول على اليمين |
| خط فاصل | ظاهر (الافتراضي) / مخفي | بين العمودين، ويظهر الزر فقط مع عمودين |
| مسودة تحت كل سؤال | بدون (الافتراضي) / صغيرة 34pt / متوسطة 68pt / كبيرة 112pt | PDF وWord فقط |
| شكل المسودة | تلقائي / أسطر / مربعات / إطار فارغ | «تلقائي»: مربعات للسؤال الرياضي المصوّر وأسطر لغيره. يظهر الزر فقط مع مسودة |

## كيف يُحدَّد الحد الأعلى ولماذا يختلف
`services/export_service.max_questions_per_page` يقيس أسئلة الكويز بنفس كود الرسم (النصية بدقة، الرياضية بتقدير
محافظ) ويأخذ السؤال «النموذجي» (الشريحة 75%): كويز بأسئلة قصيرة وتنسيق «بسيط» يسمح بـ 7، وبطاقات «عصري» أو
أسئلة طويلة تقلّل الرقم. Word له حد منفصل (`max_questions_per_page_docx`) لأن صفحته أصغر. شاشة الاختيار تعرض
أزراراً للقيم الصالحة فقط وتقبل رقماً مكتوباً مع رسالة خطأ توضح الحد.

## تقسيم الصفحة والمسودة (PDF وWord)
- **عمودان:** `export_layout.plan_column_pages` يوزّع الأسئلة على الأعمدة بقياس حقيقي بعرض العمود. مع رقم ثابت يُقسَّم بالتساوي
  (`ceil(n/2)` لكل عمود)، ومع «تلقائي» يمتلئ العمود الأول ثم الثاني، والصفحة الأخيرة تُوازَن بين العمودين.
  المسافة بين الأسئلة موحّدة في العمودين فتصطف الصفوف. PDF: الخط المنصّف مرسوم يدوياً. Word: قسم متصل بـ `w:cols`
  وخط فاصل أصلي (`w:sep`) وفواصل أعمدة/صفحات صريحة عند تحديد رقم؛ بدونه يرتّب Word العمودين تلقائياً.
- **16 بالصفحة:** ممكنة بعمودين مع أسئلة قصيرة. بالتخطيط المضغوط (عمودان، أو 8+ بالصفحة) تُرتَّب الخيارات القصيرة
  **شبكة 2×2** في PDF دون تصغير الخط؛ إن لم يتسع خيار بسطر نصف عرض تبقى القائمة العمودية. الحد الأعلى المعروض للمعلم
  يُحسب من أسئلته وتنسيقه وإعداداته الحالية (المسودة تخفّضه، والعمودان يرفعانه). Word لا يضغط الخيارات (قائمة عمودية)
  فحده أقل من PDF للكويز نفسه.
- **الأسئلة الرياضية المصوّرة:** تُرسم بعرض العمود بنفس مقياس الخط (`plan_print_blocks(q, is_ar, width_px)`). معادلة/جدول
  أعرض من العمود، أو سؤال أطول من عمود، يأخذ **صفحة بعرض كامل** (PDF: صورة بعرض الصفحة؛ Word: قسم بعمود واحد) ثم تعود الأعمدة.
  فشله بعرض الصفحة أيضاً يرفع الخطأ الصريح المعتاد.
- **المسودة:** تُحتسب ضمن ارتفاع السؤال فلا تُقصّ ولا تنفصل عنه. PDF: رسم متجهي (أسطر منقّطة / شبكة 4مم / إطار متقطع، وتسمية
  «مسودة»/Draft للشبكة والإطار). Word: صورة PNG صغيرة بعرض العمود (نفس الشكل في Word وLibreOffice).
- **التنسيقات:** بسيط/عصري/أكاديمي كلها تعمل بالأعمدة (البطاقات والفاصل الأكاديمي بعرض العمود)، والعربي RTL والإنجليزي LTR.
- **Excel** لا يتأثر بالأعمدة ولا بالمسودة. الإجابات (نسخة الأستاذ) تبقى بعمود واحد في صفحة جديدة.

## منع التزاحم والقص
- PDF: `_render_questions_paged` يقيس ارتفاع كل سؤال (نفس كود الرسم على قماش وهمي) ثم `export_layout.plan_pages`
  يجمعها؛ ما لا يتسع يُنقل لصفحة جديدة، والفراغ المتبقي يُوزَّع بين الأسئلة (حد أقصى 42pt). سؤال أطول من صفحة
  يأخذ صفحته ويتابع بآلية المتابعة نفسها.
- إصلاح مرافق: بطاقة «عصري» الأطول من صفحة كاملة كانت تُقصّ؛ تُرسم الآن كنص عادي متتابع.
- Word: ترتيب الصفحات يتولاه Word، فالتخطيط **تقديري** (فاصل صفحة قبل كل مجموعة + منع تقسيم السؤال + هامش أمان
  10%). عُويرت التقديرات على LibreOffice؛ تحقق منها في Word نفسه قبل الاعتماد عليها.

## مسار الإعدادات
`xo|<action>|<arg>|<style>|<favorite_id>` (≤ 64 بايت) → `handlers/export.export_settings_action` → تُحفظ في
FSM تحت `export_options` (Redis، انتهاء بعد 24 ساعة خمول، وتُمسح بمسح الجلسة) → عند زر الصيغة تُقرأ وتُتحقق ثم
`build_quiz_pdf/docx/xlsx(..., options)` أو `offload.remote_build_quiz(..., options.to_dict())` → `offload_worker_core`
يتحقق منها من جديد. إدخال النصوص يستعمل حالة مستقلة `ExportState.waiting_for_value` فلا يلتقطها معالج الملفات
كمحتوى كويز. التعليق على الملف المُرسل يذكر الإعدادات المطبّقة.

## النشر
انشر سيرفر الرسم (`render_worker`) **قبل أو مع** البوت: نسخة قديمة منه تتجاهل `options` بصمت فيخرج الملف بلا إعدادات،
والأقدم من هذا التعديل يرفض الحقول الجديدة (`columns`, `column_divider`, `draft_size`, `draft_style`) برسالة «إعداد تصدير غير معروف».
لا تغييرات على قاعدة البيانات.
